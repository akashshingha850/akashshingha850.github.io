# akashshingha850.github.io

Personal academic site of Akash Shingha Bappy, live at <https://akashshingha850.github.io>. Built on [al-folio](https://github.com/alshedivat/al-folio) (MIT).

Pushing to `main` runs `.github/workflows/deploy.yml`, which builds the site and publishes it to the `gh-pages` branch.

| To change | Edit |
|---|---|
| Name, URL, site settings | `_config.yml` |
| Bio and photo | `_pages/about.md`, `assets/img/prof_pic.jpg` |
| Publications | `_bibliography/papers.bib` (`selected = {true}` puts a paper on the home page) |
| Projects | `_projects/*.md` |
| News | `_news/*.md` |
| Social links | `_data/socials.yml` |
