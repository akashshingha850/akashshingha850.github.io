A coding agent that runs entirely on two RTX 6000 Ada GPUs and plugs into VS Code. No code, prompt or file leaves the machine.

- vLLM serving with one command each to pull weights, start, and self-test chat, tool calling, autocomplete and embeddings.
- Generates the VS Code (Continue) configuration automatically.
